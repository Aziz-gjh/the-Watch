THE WATCH / WEB PREVIEW

A web workspace for field observations.

This version reviews exported observations. It does not scan nearby radios or run detection algorithms.

Bring your own session

Import Fieldwatch’s Share log CSV or JSONL export, a JSON array of the same records, or a The Watch JSON export. Import replaces the current session after the entire file validates. Files are processed locally; maximum 10 MB and 50,000 observations.

Why a collector is still needed

Websites have no standard nearby Wi-Fi scanning API. Web Bluetooth provides limited, permission-based access on supported browsers, rather than Android’s passive scanning. A future companion collector could feed this workspace.

Keep your data in your hands

The session, notes, and watchlist are saved locally when browser storage is available. Export view downloads only the filtered radios, including their notes and identifiers. Clear local data removes this app’s saved workspace. Browser storage is not encrypted by this app.

No accounts, analytics, external fonts, map requests, or backend. Independently built; not an official Fieldwatch release.
